## 7. 回归清单的裁剪规则

| 本次改动类型 | 回归范围建议 |
| --- | --- |
| 前端展示 / 文案类 | 对应端全部页面展示 + 兼容性抽验 |
| 采编 / 数据字段类 | 采编系统栏目 + 基础服务入库 + **全部下游消费方**（统计系统、网站后台业务管理、网站后台预投票、H5 子系统、业务系统、沪港通子系统、先行赔付系统） |
| 股权处理类 | 业务系统前台股权处理全流程 + 统计系统股权申请审核 + 股权文件解析入库 + 股权自动化处理流程 |
| 路径 / 跳转类 | 相关入口全部跳转地址逐条比对 |
| 小程序嵌 H5 类 | 小程序对应栏目 + H5 端同页面 + 返回链路 |
| 通用/框架类改动 | 全量（按本清单 1–6 全部执行） |

## 8. 回归结论的书写要求（写入测试报告）

回归结论**不得**只写"回归通过"。应包含：

1. 回归**范围**（引用了哪些子系统/模块，与清单的差异及原因）；
2. 各子系统的**通过率与失败清单**；
3. **未覆盖项及原因**（如设备/浏览器未覆盖、环境限制、依赖外部配合）；
4. 遗留风险的明确表述（例如"未覆盖的浏览器与机型可能带来结果异常，本结论不隐含兼容性验证通过"）。
