# 通用与业务两类测评

用户确认：通用复用 Darwin 九维；业务因 Skill 而异，来自产出物 Sheet 统计及人工增加指标。

- R1：通用测评固定九维权重 7/12/12/6/18/4/12/23/6；逐维展示得分、证据、总分和加权短板；实测表现必须使用真实产出。
- R2：业务指标按项目和 Skill 保存；支持 Sheet 统计、人工定义的评委量表、人工评分。名称、方向、容差、目标值由用户明确配置，不预设所有 Skill 通用的业务好坏规则。
- R3：指标来源 Sheet、列、行/匹配条件和聚合方式可定位；基线及候选使用同一规则；缺数据、公式无缓存、零分母、重复单值不得当作零分或通过。
- R4：实验冻结指标配置，后续配置修改不追溯影响旧实验；人工指标记录数值、证据、操作人和时间，绑定本轮输入及实际产出。
- R5：通用分数独立呈现，只作诊断；选优要求通用评测完整、必需业务指标完整且不退化/满足配置目标，同时实际产出盲评通过；不把两个分数混成总分。
- R6：页面可选取 Sheet 统计项、新增评委量表/人工指标、查看两类测评结果、补录人工评分；仍走现有隔离候选、预算和发布审批。
