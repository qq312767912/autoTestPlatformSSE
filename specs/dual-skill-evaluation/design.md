# 设计

复用已接入的独立 LLM 调用、预算、真实重跑与指纹绑定。新增通用九维评分服务，评估包结构及实际产出，严格校验九个维度的 0–10 分、依据与证据；总分 Σ(score*weight)/10，短板 weight*(10-score)/10。沿用 Darwin 九维名称、权重和结构/实测分类，不将作者个人文风作为平台业务规则。

新增 SkillEvaluationProfile(project, skill, metrics)；EvolutionExperiment 新增 assessment_config JSON 冻结快照，子实验继承。业务定义包括 source(sheet/judge/human)、selector、criterion、direction(higher/lower)、tolerance、target、required。Sheet 可取唯一匹配数值、列求和/均值/数量；不猜统计方向。评委量表按用户给定标准评价实际产出；人工评分必须有证据。所有指标缺失都显式标记，必需项缺失阻断选优。

Sheet 目录从原任务产出 Excel 和 Skill report.sheets 声明读取，真实重跑的 report_sheets 使用与报告渲染一致的去重语义。平台生成的标准审查统计使用共享统计适配器；它是产物格式适配，不是所有 Skill 的固定业务指标。没有配置任何业务指标时允许运行通用测评并展示待配置，但不能发布。人工新增指标支持评委自动执行和人工评分两种方式。

新增指标配置 GET/POST 和人工业务评分 POST API；前端在创建前编辑并保存 profile，创建实验后不能变更冻结规则。两类结果独立展示。旧实验 assessment_config 为空时沿用旧流程，避免伪造补齐历史测评。

验证：九维权重/非法评分、Sheet 数值与匹配唯一性、多分片去重、人工指标缺失、各 Skill 配置隔离、配置冻结、指标退化及发布二次校验、预算归集、前端类型与构建。

## 实现补充

通用服务接受任意结构的实际输入，不绑定用例行结构；当前 A/B 运行入口通过用例审查适配器接入。Excel 统计从同一 `_write_report` 渲染器在内存生成并解析，原任务/原报告不被改写。标签匹配优先于固定地址，可用聚合起始行排除表头；公式不在服务端执行，缺缓存则显式不可测。

通用评委每个变体独立调用一次，返回完整九维证据；实际产出盲评仍采用三个独立上下文。人工定义的业务评委量表按当前 Skill 的标准独立评价，不写死指标名称。人工补评分仅在待选优阶段接受，保存人、时间及产出绑定；不花费额外模型调用。

模型调用预算覆盖候选生成、盲评、通用评委和业务评委；估算 Token 默认 40 万，可显式调整至 200 万，避免新增两类测评后只能降低预算。两类评分没有混成一个排序分数。
