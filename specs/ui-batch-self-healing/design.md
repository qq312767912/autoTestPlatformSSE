# 业务用例批量探索转换设计

## 已确认的产品边界
唯一入口位于用例管理，名称“业务用例转 UI 用例”。支持勾选多条业务用例。内部执行 Skill + AI 探索；真实执行时复用、维护或创建 UI 用例，自动记录来源关系。执行前必须确认环境。
UI 自动化页删除转换入口及重复命名的 AI 生成入口，保留 UI 资产管理、执行；独立批量自愈沿后续执行流程实现，不再要求业务用例逐条绑定操作。

## 技术依据
已有 orchestrator_integration/ui_generation_runtime.py 提供环境/登录态校验、功能步骤快照、真实浏览器工具及试跑证据校验绑定，可直接扩展。当前 validate 范围及 bind_generated_case 均拒绝已绑定用例；这是支持复用维护的实际阻碍。现有 BusinessCaseConversionModal 仅保存草稿，不适合作为新流程执行核心。旧纯 AI 探索入口依赖前端流与自由文本提示，不作为新批量任务的权威状态来源。

## 入口与配置
列表支持从勾选项进入，无勾选时可在配置弹窗选择。必填目标 UI 模块、已启用且有有效地址的环境、执行能力、可运行 Skill 精确版本；可选与该环境匹配的登录态。显示项目、源用例数量与已关联 UI 用例数量，提交前展示范围摘要。
配置由后端再次验证并固化：项目、源用例内容/步骤及时间戳、已有 UI 用例 ID、目标模块、环境地址、登录态 ID、执行器、Skill 版本及包指纹。日志不得记录密钥。

## 执行与复用
1. 创建服务端批次与独立条目，异步调度，每条独立记录会话和尝试。
2. 有来源关联的 UI 用例优先复用；跨项目/不可访问绑定拒绝执行，不能偷偷改绑。仅名称相似的资产列为候选，不自动覆盖。
3. AI 读取锁定范围，使用现有 UI 浏览器工具探索，业务断言不能被改写；目标 URL 和登录态从固化配置注入。
4. 新建或维护 UI 页面、元素和步骤。共享元素变更需限定影响范围，候选修复保留旧值和资产版本，冲突转人工。
5. 使用同环境执行，验证执行记录确属本任务、用例、用户及环境；有实际步骤和断言、所有步骤通过且资产已保存，才标记转换完成并绑定来源。
6. 构建失败、登录受阻、环境异常、业务断言失败、无有效变更等分别记录，不以模型回复或流结束判定成功。

## 服务端状态与接口
批次：待执行、执行中、完成、部分失败、取消；条目：排队、探索、维护资产、试跑、成功、失败、待补充、取消。成功结果细分新建/复用/更新。
提供创建、批次详情、条目详情、取消接口；创建支持幂等键并校验权限和跨项目范围；Celery 调度，页面仅提交与查询，不承载任务生命周期。取消停止新派发并回收当前会话；共享用例禁止并发覆盖，以版本快照检查乐观冲突。
现有来源绑定工具扩展为：新建时绑定；已有绑定仅允许维护原目标；试跑证据和源内容检查不得降低。

## 验证
后端验证配置错误、权限、精确版本、已有绑定复用、来源变更、共享资产冲突、幂等、取消及多用户隔离；故意让模型只回复成功，必须不能完成任务。真实浏览器验证至少两条源用例，一条新建一条已有关联，验证业务断言未变、真实执行通过、刷新或关闭页面任务仍继续。前端验证选中项带入、配置联动、入口唯一、逐条结果与批次统计一致。
