# 业务用例批量探索转换（按最终确认范围）

## 目标
仅在用例管理提供“业务用例转 UI 用例”。用户批量选择业务用例后确认环境，由锁定的 Skill 指导 AI 真实探索执行，边执行边维护已有 UI 资产，没有关联时创建并自动建立来源关系。

## 验收条件
1. 用例管理的勾选项带入转换配置，也可在配置中跨页选择，单次 1–100 条；UI 自动化不再提供转换入口。
2. 执行前必须确认项目、目标 UI 模块、环境地址、可选登录态和 Skill 精确版本。本期执行器固定为平台录制器浏览器，前端明确展示，不自动选择其他在线执行器。
3. 后端固化范围与业务步骤；同一批次共用一个会话，批次异步执行，关闭页面不取消。逐条展示排队、探索试跑、成功、失败、待人工处理和取消，重新打开可恢复当前批次。
4. 已关联 UI 用例必须维护原对象，禁止偷偷改绑；没有关联时复用适用资产或新建。来源步骤改变或环境配置改变须重新确认。
5. 只有真实试跑通过、执行人及环境匹配、定义新鲜且绑定工具验证成功，才算转换完成；模型回复成功不能替代证据。
6. 已有 UI 业务断言和首次试跑断言不得被自动弱化或替换。缺少断言、账号、环境或有效证据时保留记录并标记待人工处理。
7. 同一业务用例正在转换时不接受第二个批次；重复启动同一任务不重复派发。取消后停止后续条目，当前条目通过执行进程监测停止信号，在安全检查点退出。
8. 普通用例列表移除旧执行及执行队列入口；UI 自动化保留已有资产管理与执行能力。

## 本期边界
复用现有 UI 生成任务、浏览器、脚本工具和试跑证据校验；不修改 Skill Hub 原始包。Excel 可先导入用例管理后走统一流程。独立 UI 批量执行自愈并非此次探索转换入口改造的交付内容。

## 增量：UI 自动化批量自愈（2026-11-17）
用户明确要求在 UI 自动化用例列表提供独立批量自愈；扩展上述本期边界。
- 保留普通批量执行，新增“批量执行并自愈”，仅针对已有 UI 用例。
- 确认环境；顺序首跑，成功项不消耗 AI，失败项最多修复一次并由平台重跑。
- 环境沿用所选配置，登录态沿用页面步骤；无步骤、无断言、跨项目或登录态环境不符时拒绝启动。
- 仅真实本轮执行记录可判定成功；区分首跑通过、自愈通过、失败/待处理。保留首跑与重跑记录 ID。
- 同批次一个会话；关闭窗口后台继续；本地恢复进度；停止后续任务需二次确认。
- 保留原业务断言，禁止删改断言、替换用例或重绑业务用例；共享资产修改影响所有引用，界面说明。
