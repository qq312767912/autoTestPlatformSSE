# 上证 e 投票 Skill 数据飞轮上线与回滚手册

## 上线检查

1. 执行 `python manage.py migrate --plan` 并备份数据库；新表只增加历史包、回放差异和项目开关，不改写存量生产链。
2. 执行 `audit_workflow_skill_locks` 和 `audit_flywheel_isolation --fail-on-error`；前者发现问题时自动以非零状态退出。
3. 确认上证 e 投票项目的四阶段 Skill 版本已从公开 Skill Hub 选定并锁定。
4. 由测试负责人建立并发布首版业务分类和关键场景；冻结前清空未复核案例与未仲裁冲突。
5. 调用 `POST /api/knowledge-evolution/flywheel-settings/set/` 仅开启目标项目，检查其他项目开关仍关闭。
6. 跑完项目 A/B 隔离、历史包预检/确认、回放人工判定、关键退化阻断和前端构建。

## 异常补偿

- 候选事件失败：在资产审核工作区按单条或批量重试；达到上限后进死信，不自动确认金标。
- 文件哈希变化：废弃旧预检凭证重新预检；不跳过哈希校验。
- 回放不确定：保持 `needs_review`，由测试负责人逐项判定；未完成不得用于晋级。
- 关键案例退化：保持 `blocked`，修复候选 Skill 后建新回放；不改写旧结果。

## 回滚

1. 立即关闭目标项目的 `ProjectFlywheelSetting.enabled`；旧需求、Agent 对话和测试管理流程不依赖该开关。
2. 停止新历史包确认和回放任务；保留已有审计、候选与回放记录供排查。
3. 回滚已晋级 Skill 时使用平台现有发布指针/回滚服务，不删除历史版本。
4. 若需回滚数据库，先确认新表中的审计记录已导出；迁移回滚只删除新表，不影响存量表。
