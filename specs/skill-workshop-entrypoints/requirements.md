# 数据飞轮入口与 Skill 工坊

- 独立能力测评评估完整业务能力，包括模型、Prompt、Skill、工具链及组合效果；Skill 工坊处理定向 Skill 改进，不能合并两者。
- 代码审查与其他独立能力同级展示卡片；初始不挂载专用测评集组件，点击进入，返回恢复卡片。
- Hub 通用测评可进入数据飞轮的 Skill 工坊，保留项目、精确版本与已有测评会话，不能新建聊天任务或默认切换到最新版本。
- 工坊提供通用测评/私有候选入口，以及现有用例审查业务任务与历史实验入口。任务证据沿用服务端已绑定版本，不接受在 Hub 粘贴产出。
- 工坊材料选择器展示全部可用业务 Skill，区分已在工坊和已移出，支持搜索、定位及重新加入；平台基础工具排除并明确说明。无结果、加载失败和已在工坊须区分。
- 定位来源版本不可见、已移出、跨项目时必须说明，不能静默替换来源版本。找不到来源业务任务时不能自动选另一任务。
- Hub 原件不变；私有候选仅经显式确认才可提交为新版本。
