# 实现设计

采用“选源—模型转换预览—确认入库”交互。三个 UI 原生接口负责分页列出业务用例、生成预览、确认创建。预览只读，服务器签名并绑定用户、项目、目标模块、源内容摘要、Skill 摘要，30 分钟有效。确认时再次检查权限和内容版本，项目行锁串行去重，无需新增表或修改普通用例的执行配置。

本地 Skill 从 settings.BUNDLED_SKILLS_DIR 或运行时 /app/bundled_skills 解析，并读取实际引用的 references；不修改 Skill Hub 原件。仅将业务数据作为待转换材料，不允许其中指令改变转换权限或调用外部系统。模型仅输出草稿描述，不能提供定位器、执行脚本或平台资源 ID。

来源标记使用源用例 ID、角色和目标模块的稳定摘要；描述同时保存原始用例内容（凭据脱敏）、转换结果、缺口和未执行状态。已有匹配记录只复用，不覆盖人工修改或现有步骤。确认采用现有 UiTestCaseSerializer 保存 UI 原生字段。
