# Skill Hub 独立通用测评与进化

用户确认：直接从 Skill Hub 选一个 Skill 做通用测评，也能生成候选和进化，不依赖用例审查或业务测评。

- R1：Hub 卡片与版本历史均提供通用测评入口，明确选择精确版本、项目内保存历史，跨项目 Hub 原材料可读，项目测评记录不可越权。
- R2：无需业务报告即可做结构体检；九维中实测表现未执行时不得补分或显示完整百分制分数。可选文本实测或人工提供真实产出复核，来源明确。
- R3：文本实测不能模拟脚本/浏览器/外部工具；此类 Skill 可做结构体检或提交实际产出，无法执行的任务必须失败。
- R4：从测评短板生成人工可审阅的最小补丁和 diff，候选只落项目工作副本，Hub 原件与活跃指针不变。
- R5：候选沿用同一测试输入重新测评；完整实测后做独立成对验证，人工选择下一轮基线，最多三轮并受预算约束。结构体检候选可继续加工，但不能冒充已验证提升。
- R6：只有完整测评、成对验证通过、人工确认 diff 与理由后才可新增回 Hub 审批；不自动激活。历史及失败记录可重新打开。


## 2026-11-04：真实产出复核转入 Agent 任务

- Hub 仅提供结构体检与文本任务实测，不接收人工粘贴文件内容、来源或候选产出作为真实执行证据。
- “前往 Agent 任务执行与复核”按所选精确 Hub 版本创建全新会话，服务端绑定项目、用户、版本 ID 与包 SHA256；每次执行重新校验，恢复历史不能丢失绑定，改链接或请求不得换版本。
- 实际执行、文件交付和复核留在 Agent 任务中；本入口不把 Agent 交付结果自动计入通用评分。
- 旧 external 历史只读，禁止新建、测评、候选加工与提交，队列中的旧任务也须拒绝执行。
