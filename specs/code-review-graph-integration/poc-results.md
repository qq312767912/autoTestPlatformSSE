## 解读限制

- Token 和耗时可直接对比；两组任务均保持 70/70 Diff 文件覆盖。
- “确定缺陷采纳率”若仅按平台核验分类计算，基线为 11/12（91.67%），增强组为 4/7（57.14%）。这只是平台内部代理指标，不等同于人工采纳率。
- 本次没有人工金标和逐条复核，因此不宣称真实漏报率、误报率或质量提升。LLM 输出存在非确定性，最终结论数变化需要人工盲评。
- PoC 结果支持继续小范围实验，尚不支持立即开发长期图谱缓存或前端影响链。
