# 代码审查独立测评

入口：数据飞轮 → Agent 独立测评 → 代码审查。

当前支持导入公开或内部测评集的**平台标准 JSON**。公开基准的原始文件尚需转换；仓库须先登记到当前项目，确保每条样本的 base/head Commit 在该仓库中可访问。

```json
{
  "cases": [
    {
      "repository_id": "平台仓库编号",
      "base_sha": "0123456789abcdef0123456789abcdef01234567",
      "head_sha": "89abcdef0123456789abcdef0123456789abcdef",
      "language": "python",
      "source_url": "https://example.com/pull/1",
      "issues": [
        {"file": "src/auth.py", "line": 42, "description": "无效令牌仍被接受"}
      ]
    }
  ]
}
```

语言只能是 `python`、`java`、`c++`（也接受 `cpp`）。`issues: []` 表示干净 PR，不能省略。一次导入 1～1000 条。导入时可填写来源名与数据版本；测评运行会锁定标准审查模式和模型配置名称，不覆盖原代码审查任务。

运行报告中的候选匹配仅辅助人工核验。核验每个金标是命中还是漏报，并逐条判定未匹配发现是有效但金标缺失还是误报后，才计算该语言和整次运行的正式指标。失败与部分完成的样本不计入质量指标分母，须单独处理。报告可导出 JSON，包含逐样本证据及核验记录。

当前未实现公开基准的原生下载/转换、自动登记仓库、C++ 样本扩充和 CRG 开关配对运行；不得把标准 JSON 导入能力描述为这些能力已经完成。
