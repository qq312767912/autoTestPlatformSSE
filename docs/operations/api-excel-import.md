# 旧接口自动化平台 Excel 导入

入口：接口自动化 → 场景用例 → Excel 导入。选择 .xlsx / .xls，可指定当前项目分组，先解析预览再确认。当前兼容 AutomationTestCase / AutomationCaseApi 多工作表导出结构，不是任意 Excel 表格。

映射：
- AutomationTestCase → 场景用例；AutomationCaseApi → 内嵌请求步骤，按旧 order 排序并重编连续顺序。
- GlobalHost → 用例 base_url；选择执行环境时可覆盖相对地址的主机。多主机用例保留步骤完整地址并提示。
- AutomationHead / AutomationParameter → 请求头、查询参数或表单；Raw 请求支持明确的原始请求体列。
- AutomationJsonAssertData → JSON 字段/数组下标断言，转换为 body JMESPath；保留 HTTP 状态断言。复杂路径、脚本/数据库检查等不能可靠迁移的配置阻止导入。
- 旧 {{变量名}} 转为平台变量，兼容环境中原变量名；外部 relation[库][表][字段] 转为稳定的迁移变量，并保留完整来源说明。文件中没有的外部源值必须补齐，不能使用历史响应或历史参数替代。
- 历史结果、报告和其中的历史 token 不导入；未启用前置脚本不执行。新导入资产不会自动发起请求。

预览检查重复名称、断开的关联和无法支持的字段；确认后在事务中创建全部资产。同名用例阻止整批导入，绝不覆盖。确认会重新解析文件并校验 SHA256。需要当前项目成员身份及新增场景用例权限。

执行前在用例变量或执行环境中补齐预览列出的变量；遗漏时在任何网络请求前报错。替换步骤中的迁移占位符后对应变量不再必填。编辑保存保留迁移元数据与检查；导入的内嵌请求可以直接在场景用例编辑器修改，不要求创建新的接口定义。

限制：20MB 文件，解压后100MB，单表最多50000行、100列。XLSX 公式不执行且要求转为值。无模型迁移；更新 Web 后端与前端，现有依赖已包含 openpyxl/xlrd。
