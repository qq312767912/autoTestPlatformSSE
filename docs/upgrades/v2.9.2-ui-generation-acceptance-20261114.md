## 验收发现并修复

1. 执行器虽然接受API Key配置，获取用例数据时却仍请求密码登录，导致3次真实执行失败（54/55/56）。已优先使用Key兑换JWT，失败不回退到密码；原有密码登录仍支持。修复后真实执行与原断言通过。
2. 停止任务后历史工具调用可能没有结果消息，恢复时模型返回400。新增最终模型请求配对守护；缺失结果明确标为中断错误，不伪造执行成功，再恢复原任务验证通过。
3. UI生成页跳转未携带任务定位，刷新初始化可能丢失当前会话选择。跳转改为携带服务端任务ID与项目，并复用已有精确版本恢复入口。
4. 已绑定Skill的任务没有个人提示词时仍弹出配置窗口。引导增加服务端任务身份核对，普通对话的配置引导保留。
