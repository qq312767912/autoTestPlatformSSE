# 测试用例清晰度审查

把测试用例当作可独立执行、可复现、可判定的验收说明进行审查。

1. 识别前置条件、测试数据、操作步骤和预期结果的缺失。
2. 检查步骤和可观察结果是否对应，最终业务结果是否被验证。
3. 区分确定缺陷、待业务确认和优化建议。
4. 保留源 Sheet、行号、用例编号、模块、名称和原文，保证可追溯。
5. 不凭空补造未知业务规则；无法确定的标准标记为“待业务确认”。
6. 高风险问题必须经过语义复核，不能仅按关键词机械定级。

严重程度：高表示核心错误仍可能被判定通过；中表示不同执行人可能得出不同结论或遗漏重要边界；低表示主要影响效率、维护与证据追溯。
