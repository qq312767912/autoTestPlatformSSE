# 报告结构

## 代码变更分析报告

- `summary`: 文件数、风险数、覆盖率
- `files`: 变更文件
- `findings`: 变更、风险、证据、检测来源、影响范围、置信度
- `impact_summary`: 聚合后的影响范围
- `analysis_note`: 未分析内容和降级说明

## 测试分析报告

- `summary`: 测试点、优先级、覆盖缺口统计
- `test_requirements`: 标题、目标、预期、类型、优先级、来源风险、状态
- `regression_suggestions`: 建议回归的模块或历史用例
- `coverage_gaps`: 尚无测试覆盖的风险
