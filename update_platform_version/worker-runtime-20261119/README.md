# 内网并发与 Web 故障隔离补丁

替代 worker-isolation-20261119 初版。只适用于采集的 `wharttest-250-backend:update-20261109-ai-coverage-r1-arm64` 和原始 Supervisor SHA256；若安装过旧补丁，不要强行绕过版本校验，请重新采集。

## 执行

暂停提交任务、等待任务完成后，在部署服务器解压并执行：

```bash
sudo bash apply.sh 2>&1 | tee apply-result.log
```

修改前保存独立备份与容器ID。使用目标Python在临时目录生成候选配置并编译，再安装；后端健康并且8001可访问后才切前端Nginx，失败自动回滚。输出备份绝对路径。不会修改宿主机hosts、数据库结构或清空队列。日志和备份可能包含业务信息，不应上传Git。

Web：8000保留一个有状态进程，8001三进程承接基础接口；卡死120秒后先保存栈再恢复该Web进程。
Celery：六个独立solo消费者，每类单并发；代码审查全局串行限制保留。历史默认队列继续由default消费者自然排空。

## 验收及回滚

`sudo bash check.sh` 检查消费者进程、后端健康及前端到基础接口连通性。再从页面检查登录、项目选择、审查提交和执行器连接。

暂停提交、等待运行任务结束后：

```bash
sudo bash rollback.sh /绝对路径/backup-时间
```

回滚恢复原前端及业务配置，原单消费者额外监听所有新增队列，避免遗留消息无人消费。回滚会重启后端，未结束任务可能中断。自动回滚无法保证已经执行任务的业务副作用撤销。

重启同一容器保留补丁，重建容器会丢失。该补丁不修复模型网关本身的120秒超时，不保证35个重型任务同时执行。安装前仍须目标ARM64/64KB运行时预检；本地Docker测试不代表目标内核兼容性验收。
