# 内网 ONES 地址临时补丁

目标为已发布的 update-20261119-89ffd9ef-r2-arm64 后端原版 ones_import.py，仅替换原域名为 https://10.122.212.49:60000，不增加数据库字段，不修改前端。

在内网确认没有执行中的长任务后执行 `sudo bash apply.sh 2>&1 | tee /tmp/ones-hotfix.log`。将重启后端，正在运行任务可能中断；不清理队列。

先检测后端到ONES的HTTPS链路，证书不匹配/不受信任时停止，不关闭TLS验证。无需邮箱密码即可检查接口是否可达；这不等同账号登录成功。

核对镜像标签和原文件SHA256，保存原文件及容器ID，在目标Python预编译后替换一个地址字符串，失败自动回滚并检查健康。手动回滚：`sudo bash rollback.sh /绝对路径/backup-时间`。

本补丁不重建容器。若后来重建了容器，临时修改将丢失；下一版完整镜像将使用本地新增的全局ONES地址配置功能。保留备份，不要用本地新版ones_import.py整文件覆盖内网旧版。
